# Neon Hover Runner

A neon cyberpunk 3D endless runner built with Next.js, React Three Fiber, and Zustand.

## Setup

```bash
cd 3D_Game_Cursor
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run start` | Start production server |
