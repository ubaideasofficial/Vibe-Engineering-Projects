## 6. AKMEC INDUSTRIAL OS

**Concept:** precision instrument panel for heavy industry. Cold engineered steel, safety-signal accents, machined depth. Credibility first; expression second.

### Tokens

```css
--steel-950:#0A0E14; --steel-900:#111722; --steel-800:#1A2231;
--steel-600:#3A4657; --steel-300:#A7B2C2; --steel-100:#E8ECF2;
--steel-050:#F5F7FA; --safety:#FF6A00; --signal:#00C2A8;
--warn:#FFC53D; --danger:#E5484D; --ink:#0B0F16; --paper:#FFF;
```

Safety orange ≤10% of a viewport.

**Type:** Display = tight geometric grotesk (Space Grotesk/Archivo/Chakra Petch), uppercase, `-0.02em`; Body = Inter/IBM Plex Sans, 16–18px, 1.65; Mono = JetBrains Mono/IBM Plex Mono for technical codes. Scale: 12/14/16/18/21/28/38/52/72/96, fluid.

**Layout:** 8px grid; sections 96–160px desktop, 64–80px mobile; max 1280px, bento 1440px; radii `8/14/22/32/36/999`.

### Shared effects — define once, reuse

* **Glass:** translucent white, blur(20px), saturation 160%, hairline border, deep shadow.
* **Neumorphism:** light `--steel-100` only; raised/inset dual shadows.
* **Clay:** radius 36px, white→steel gradient, large soft outer + inset highlights.
* **Skeuomorphic metal:** brushed-metal gradient + repeating grain + machined bevel.
* **Brutal:** white/black, 3px border, zero radius, `8px 8px 0 #000`; hover translate up-left/deeper shadow.
* **Liquid Glass:** blur 24px, saturation 180%, bright translucent gradient, specular pointer-tracked highlight, subtle chromatic/inset edge.

### Motion

`cubic-bezier(.2,.8,.2,1)`; 180ms micro / 420ms card / 700ms section. Reveal: 16–24px + opacity, 60ms stagger. Parallax: bg `.15x`, mid `.4x`, foreground `1x`. Reduced motion: no transforms; opacity only.

### Accessibility — blocking

Contrast ≥4.5:1 everywhere; opaque text tint if needed. Neumorphic controls require visible border + `2px solid --safety` focus ring/2px offset. Logical headings, full keyboard nav, skip link, semantic landmarks, descriptive alt text. Motion must not convey required information.
